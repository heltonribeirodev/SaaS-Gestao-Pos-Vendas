# Histórico de Alterações

Todas as modificações importantes deste projeto serão documentadas neste arquivo.

----------

## [1.0.0] - 31/07/2026

### ✨ Alterações Marcantes
- Versão Inicial do site conforme as demandas necessárias.

### ⚙️ Funcionalidades Adicionadas
- **CRUD:** Sistema CRUD completo para gerenciamento de usuários e de pedidos.
- **Autenticação:** Sistema de Login funcional.
- **Alteração senha:** Usuário precisa redefinir a senha após o primeiro acesso, evitando deixar a senha padrão.
- **Redefinir Senha:** Sistema de refeinição de senha funcional, com gerador de tokens e confirmação de e-mail.
- **Hierarquia:** Hierarquia de usuários funcional seguindo regras da empresa
